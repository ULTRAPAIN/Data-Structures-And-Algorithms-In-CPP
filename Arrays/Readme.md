# Arrays

**Arrays** are fundamental data structures in computer science. They represent an ordered collection of elements, typically of the same data type.

**Key Concepts:**

* **Elements:** Individual items stored within the array.
* **Index:** A unique number assigned to each element, indicating its position within the array. The index usually starts from 0.
* **Size:** The total number of elements in the array.

**Example:**

Consider an array of integers: `[10, 20, 30, 40]`

* This array has a size of 4.
* The first element (at index 0) is 10.
* The second element (at index 1) is 20, and so on.

**Why Use Arrays?**

* **Efficient Data Access:** Elements can be accessed directly using their index, providing fast retrieval.
* **Efficient Data Storage:** Arrays often store elements in contiguous memory locations, which can improve performance.
* **Versatility:** Arrays can store various data types, including numbers, characters, and even other arrays.

**Common Operations:**

* **Accessing Elements:** Retrieve the value of an element at a specific index.
* **Modifying Elements:** Change the value of an element at a given index.
* **Adding Elements:** Insert new elements into the array.
* **Removing Elements:** Delete elements from the array.
* **Searching:** Find the index of a particular element within the array.
* **Sorting:** Arrange the elements in a specific order (e.g., ascending, descending).
